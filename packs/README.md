# packs

Three JSON files: `drafts/fannie-farmer-1896.pack.json`, a pack of five recipes from the public-domain 1896 *Boston Cooking-School Cook Book*; `commons.json`, a library of cooking techniques; and `states.json`, a library of doneness states (what done looks, sounds and smells like). The pack's steps refer to entries in the two libraries by id. All three follow the format in `design/pack-format-v0.md`.
